# 나의 다음 직업 찾기 PRD

- 문서 상태: Approved v1.0
- 작성일: 2026-10-31
- 관련 문서: `product-brief.md`, `user-stories.md`, `harness-design.md`

## 1. 문제 정의

새로운 직업을 고민하는 20~40대 직장인과 자영업자는 자신이 무엇을 원하는지 충분히 언어화하지 못한 경우가 많다. 기존 진로 검사는 문항이 길고 결과가 진지하거나 추상적이어서, 탐색의 첫 단계로 진입하기 어렵다.

나의 다음 직업 찾기는 10개 이내의 모바일 질문과 작은 동물 캐릭터를 이용해, 사용자가 선호하는 업무 방식과 탐색할 만한 직무군을 가볍게 발견하도록 돕는다.

## 2. 목표

1. 사용자가 3분 이내에 테스트를 완료하게 한다.
2. 응답에 따라 구별되는 6개의 결과를 제공한다.
3. 결과를 특정 직업의 단정이 아닌 업무 성향과 직무군의 제안으로 표현한다.
4. 현재 직업에서 축적한 스킬과 전문성이 다음 직무군에 어떻게 연결될 수 있는지 보여준다.
5. 결과를 이미지로 저장해 공유할 수 있게 한다.
6. 하네스를 통해 질문, 점수, 결과 문구 및 웹앱을 재생성할 수 있게 한다.

## 3. 비목표

- 직업 적성에 대한 과학적 또는 임상적 진단
- 사용자의 진로를 대신 결정하는 것
- 성별, 나이 또는 MBTI를 근거로 직업을 추천하는 것
- 개인 데이터의 서버 저장과 분석
- 취업 준비 과정 전체를 제공하는 것
- 테스트 종료 후 행동 과제를 제안하는 것

## 4. 핵심 가설

> 진로 고민을 업무 성향과 작은 동물 캐릭터로 표현하면, 사용자는 긴 진로 검사보다 부담 없이 테스트를 완료하고 결과를 더 쉽게 이해하고 공유할 것이다.

제품 경험의 우선순위는 재미와 공유 가능성 60%, 진로 인사이트 40%다.

## 5. 측정 차원

테스트는 다음 다섯 가지 업무 성향을 측정한다.

| 차원 | 한쪽 성향 | 반대 성향 |
|---|---|---|
| 대상 | 사람 중심 | 시스템 중심 |
| 진행 방식 | 탐색 중심 | 실행 중심 |
| 사고와 표현 | 분석 중심 | 표현 중심 |
| 변화 선호 | 안정 선호 | 실험 선호 |
| 관계 방식 | 독립 작업 | 협업 작업 |

각 선택지는 캐릭터 하나에 투표하고, 동시에 다섯 차원에 `-2`부터 `+2` 사이의 가중치를 부여한다. 캐릭터가 질문에 등장한 횟수가 5회 또는 6회로 다르므로, 획득한 표를 등장 횟수로 나누어 정규화한 뒤 가장 높은 결과를 선택한다.

동점일 때는 다음 순서로 결정한다.

1. 전체 응답의 평균 성향 벡터와 더 가까운 캐릭터
2. 가장 강한 차원과 더 잘 일치하는 캐릭터
3. 그래도 같다면 사전에 정의된 안정적인 결과 순서

대표 캐릭터와 별개로 절댓값이 가장 큰 성향 축을 보조 태그로 표시한다. 전체 응답 조합 시뮬레이션에서 각 캐릭터의 결과 비율이 10~25%이면 정상 범위로 판단한다.

## 6. 입력 정보 정책

### 점수에 사용하는 정보

- 상황형 질문에 대한 사용자의 선택
- 선호하는 업무 방식에 대한 선택

### 개인화에만 사용하는 정보

- 현재 직업 분야

현재 직업 분야는 결과 점수를 바꾸지 않는다. 사용자가 이미 가진 스킬과 전문성을 추정 가능한 범위에서 다음 직무군과 연결하는 설명에만 사용한다. 직업 분야만으로 개인의 실제 능력을 단정하지 않으며, 연결 문구는 가능성으로 표현한다.

### 수집하지 않는 정보

- 성별
- 전공
- MBTI
- 실명
- 연락처
- 회사명
- 정확한 나이

성별과 MBTI는 업무 성향 점수에 불필요하고 편향을 만들 수 있으며, 전공은 현재 전문성을 충분히 설명하지 못할 수 있으므로 MVP 질문에서 제외한다.

## 7. 질문 구성

총 질문 수는 최대 10개다.

- 프로필 질문 1개: 현재 직업 분야
- 점수 질문 8개: 상황형 행동 선택 질문
- 총 질문 수 9개
- 질문당 선택지 2~4개
- 자유 입력 없음
- 모든 질문에 건너뛰기 또는 해당 없음 선택지를 검토한다.
- 점수 질문에 `매우 그렇다~아니다` 형태의 척도를 사용하지 않는다.

점수 질문은 자기평가 문장보다 구체적인 상황을 우선한다.

좋은 예:

> 엉킨 프로젝트를 처음 맡았다. 가장 먼저 하고 싶은 일은?

피할 예:

> 나는 창의적인 사람이다.

## 8. 결과 모델

결과는 다음 내용을 포함한다.

- 캐릭터 이름
- 한 줄 캐치프레이즈
- 2~3문단의 업무 성향 설명
- 보조 성향 태그
- 넓은 추천 직무군 3개와 각 직무군의 구체적인 직무 예시
- 현재 직업에서 가져갈 수 있는 스킬·전문성 연결 문구
- 잘 맞는 업무 환경
- 피로할 수 있는 업무 환경
- 5개 차원의 성향 그래프
- 캐릭터 이미지
- 엔터테인먼트형 콘텐츠라는 짧은 안내

결과 화면의 섹션 제목은 다음 구조를 사용한다.

1. 캐릭터명과 캐치프레이즈
2. 업무 성향 설명
3. `이럴 때 살아나요`
4. 추천 직무군과 구체적인 직무 예시
5. `지금 일에서 챙겨갈 것`
6. `이런 환경에서는 털이 곤두서요`

결과에 행동 과제, 장기 계획 또는 확정적인 직업 지시는 포함하지 않는다.

## 9. 사용자 흐름

### 9.1 시작 화면

- 서비스명과 한 줄 소개를 표시한다.
- 예상 소요 시간과 질문 수를 보여준다.
- `내 전직 동물 찾기` 버튼으로 시작한다.

### 9.2 프로필 질문

- 현재 직업 분야를 선택한다.
- 답변을 원하지 않거나 알맞은 항목이 없는 사용자를 위한 `기타·직접 선택하기 어려움` 또는 `건너뛰기`를 제공한다.

### 9.3 성향 질문

- 화면당 질문 하나를 노출한다.
- 선택하면 다음 화면으로 진행한다.
- 현재 진행 상태를 세계관에 맞는 표현으로 보여준다.
- 이전 질문으로 돌아가 답변을 변경할 수 있다.

### 9.4 계산 화면

- 1~2초 내의 짧은 전환 모션을 제공한다.
- 모션 감소 설정에서는 정적 상태로 대체한다.

### 9.5 결과 화면

- 캐릭터와 유형명을 첫 화면에 보여준다.
- 업무 성향, 추천 직무군, 환경 정보를 제공한다.
- `결과 이미지 저장`과 `다시 하기`를 제공한다.

## 10. 기능 요구사항

### FR-01 테스트 시작

사용자는 별도의 회원가입 없이 테스트를 시작할 수 있어야 한다.

### FR-02 응답 진행

한 화면에 질문 하나만 표시해야 하며, 선택 직후 다음 질문으로 이동해야 한다.

### FR-03 응답 수정

사용자는 이전 질문으로 돌아가 답변을 변경할 수 있어야 한다.

### FR-04 결과 계산

동일한 응답에는 항상 동일한 결과가 나와야 한다.

### FR-05 결과 설명

모든 결과는 대표 캐릭터, 보조 성향, 넓은 직무군과 구체적인 직무 예시, 현재 전문성의 연결, 잘 맞는 환경, 피로할 수 있는 환경을 포함해야 한다.

### FR-06 이미지 저장

사용자는 결과를 `1080×1350` PNG 이미지로 저장할 수 있어야 한다.

### FR-07 재시작

사용자는 결과 화면에서 모든 응답을 초기화하고 테스트를 다시 시작할 수 있어야 한다.

### FR-08 로컬 실행

생성된 웹앱은 백엔드 없이 정적 파일만으로 실행할 수 있어야 한다.

## 11. 비기능 요구사항

### 접근성

- 모든 선택지는 키보드로 조작할 수 있어야 한다.
- 텍스트와 배경은 읽을 수 있는 대비를 가져야 한다.
- 색상만으로 선택 상태를 표현하지 않는다.
- `prefers-reduced-motion`을 지원한다.
- 캐릭터 이미지에는 대체 텍스트를 제공한다.

### 개인정보

- MVP는 답변과 결과를 서버로 전송하지 않는다.
- 테스트 상태는 브라우저 메모리에서만 유지한다.
- 분석 도구는 MVP에 포함하지 않는다.

### 성능

- 일반적인 모바일 네트워크에서 첫 화면을 빠르게 표시한다.
- 결과 카드 생성은 사용자의 기기에서 수행한다.
- 캐릭터 이미지 용량을 모바일 환경에 맞게 최적화한다.

## 12. 콘텐츠 및 윤리 기준

- 말투는 장난스럽고 살짝 짓궂게 유지한다.
- 결과의 감정 흐름은 `들켰다는 공감 → 웃음 → 다른 직업에 대한 호기심`을 목표로 한다.
- 사용자의 현재 직업, 능력 또는 선택을 조롱하지 않는다.
- “적성”, “진단”, “정답”, “천직” 같은 확정적 표현을 피한다.
- 직업과 성별, 전공 또는 성격 유형을 고정적으로 연결하지 않는다.
- 현재 직업 분야에서 일반적으로 쓰이는 스킬을 참고할 수 있지만, 사용자가 실제로 그 스킬을 보유한다고 단정하지 않는다.
- 각 결과는 동일한 수준의 매력과 구체성을 가져야 한다.
- 피로할 환경을 결함처럼 표현하지 않는다.
- 정신건강 또는 치료 효과를 암시하지 않는다.
- 결과 화면에 캐주얼한 자기 탐색 콘텐츠임을 밝힌다.
- 피로할 수 있는 환경은 가볍고 재치 있게 표현하되 사람이나 직업을 비하하지 않는다.

## 13. MVP 검증 기준

### 구조 검증

- 6개 결과가 모두 도달 가능하다.
- 모든 선택지가 유효한 점수 벡터를 가진다.
- 누락된 질문, 결과 또는 이미지 참조가 없다.
- 10,000개의 무작위 응답 시 결과별 비율이 설정한 허용 범위를 벗어나지 않는다.

### 사용성 검증

- 최소 5명의 사용자가 테스트를 완료한다.
- 대부분의 사용자가 3분 안에 완료한다.
- 사용자가 결과를 자신과 닮았다고 느낀다.
- 사용자가 결과 캐릭터를 매력적이라고 느낀다.
- 모바일에서 PNG 저장이 정상 동작한다.

## 14. 확정 사항

- 서비스명: `나의 다음 직업 찾기`
- 캐릭터: 탐색하는 토끼, 뚝딱 만드는 햄스터, 계획하는 고슴도치, 연결하는 다람쥐, 창작하는 친칠라, 돌보는 수달
- 비주얼: 제작자가 직접 그린 원본 캐릭터의 픽셀브러시 조형 언어를 확장
- 결과 카드: 캐릭터, 결과명, 캐치프레이즈, 보조 성향, 직무 키워드 3개 포함
- 결과 카드 제외 정보: 현재 직업 분야, 긴 설명, QR 및 민감 정보
- 현재 직업 분야: 10개 범주별 전문성 후보를 가능성의 문장으로 연결
