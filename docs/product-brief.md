# 나의 다음 직업 찾기 제품 브리프

- 문서 상태: Draft v0.1
- 작성일: 2026-10-31
- 제품명: 나의 다음 직업 찾기
- 한 줄 설명: 10개 이내의 질문으로 나의 다음 직업 성향을 작은 동물 캐릭터로 발견하는 모바일 진로 탐색 테스트

## 배경

AI의 확산, 고용 환경의 변화, 현재 직업에 대한 불만족으로 인해 새로운 진로를 상상하는 사람이 늘고 있다. 그러나 기존 진로 검사는 길고 진지하거나, 결과가 추상적이어서 가볍게 시작하기 어렵다.

나의 다음 직업 찾기는 미래 직업을 단정하는 검사가 아니다. 사용자가 짧고 재미있는 질문에 답하면서 자신이 선호하는 업무 방식과 다음에 탐색해볼 직무군을 발견하도록 돕는 캐주얼한 콘텐츠다.

## 핵심 사용자

- 현재 직업이 자신과 잘 맞는지 고민하는 20~40대 직장인 또는 자영업자
- 이직, 전직 또는 업종 전환을 생각하지만 아직 다음 방향을 정하지 못한 사람
- 긴 진로 검사보다 모바일 심리테스트 형태의 가벼운 경험을 선호하는 사람
- 결과 캐릭터와 카드를 친구 또는 SNS에 공유하고 싶은 사람

## 핵심 가치

> 진로를 결정해주는 대신, 다음 가능성을 재미있게 상상하게 한다.

사용자는 3분 이내에 테스트를 완료하고 다음을 얻는다.

1. 자신의 업무 성향을 표현하는 작은 동물 캐릭터
2. 어울릴 가능성이 높은 직무군 세 가지
3. 현재 직업에서 다음 직무로 가져갈 수 있는 스킬과 전문성의 연결
4. 잘 맞는 업무 환경과 피로할 수 있는 업무 환경
5. 저장하고 공유할 수 있는 결과 이미지

경험의 우선순위는 재미와 공유 가능성 60%, 진로 인사이트 40%로 둔다.

## 경험 원칙

### 가볍지만 허술하지 않다

질문과 카피는 재미있어야 하지만, 결과는 응답과 일관된 근거를 가져야 한다.

### 단정하지 않는다

“당신은 이 직업을 가져야 한다”가 아니라 “이런 종류의 일을 탐색해볼 수 있다”고 표현한다.

### 사람을 분류하기보다 가능성을 연다

결과 유형은 우열이 없으며, 부정적이거나 낙인찍는 캐릭터를 만들지 않는다.

### 한 손으로 끝낼 수 있다

모바일 화면에서 한 페이지에 질문 하나, 선택지는 최대 네 개만 보여준다.

### 결과 자체가 콘텐츠다

사용자가 설명을 읽는 것뿐 아니라 결과 카드를 저장하고 공유하고 싶도록 만든다.

### 살짝 짓궂지만 사람을 비웃지 않는다

결과 카피는 장난스럽고 살짝 짓궂게 쓴다. 사용자가 “들켰다”고 느끼며 웃을 수는 있지만, 현재 직업이나 능력을 조롱하지 않는다. 결과를 읽은 뒤에는 다른 직업에 대한 호기심이 남아야 한다.

## 결과 캐릭터 초안

| 캐릭터 | 핵심 성향 | 대표 직무군과 예시 |
|---|---|---|
| 탐색 토끼 | 관찰, 조사, 호기심 | 사용자 이해: UX 리서치, 데이터 분석, 시장조사 |
| 뚝딱 햄스터 | 제작, 자동화, 개선 | 제품 만들기: 개발, 프로덕트 운영, 노코드 자동화 |
| 기획 고슴도치 | 구조화, 판단, 우선순위 | 문제 구조화: PM, 서비스 기획, 사업기획 |
| 연결 다람쥐 | 설득, 조율, 관계 형성 | 관계와 성장: HR, 커뮤니티, 세일즈 |
| 창작 친칠라 | 표현, 감각, 새로운 해석 | 아이디어 표현: 디자인, 콘텐츠, 브랜딩 |
| 돌봄 수달 | 공감, 지원, 성장 촉진 | 사람의 성장: 교육, 코칭, 고객 경험 |

캐릭터명은 기능이 바로 이해되는 형태로 유지한다. 장난스럽고 살짝 짓궂은 유머는 캐릭터명보다 캐치프레이즈와 결과 설명에서 표현한다.

## MVP 범위

- 모바일 우선 단일 페이지 웹앱
- 10개 이내의 질문
- 6개의 결과 캐릭터
- 대표 캐릭터 하나와 보조 성향 태그 하나
- 현재 직업에서 가져갈 수 있는 전문성 연결 문구
- 질문별 페이지 전환과 진행 상태 표시
- 결과 설명과 추천 직무군
- Canvas 기반 PNG 결과 카드 저장
- 키치하고 러프한 캐릭터 중심 비주얼
- 키보드 조작과 모션 감소 설정 지원
- 결과 도달 가능성 및 점수 분포 검증

## MVP에서 제외하는 것

- 회원가입과 로그인
- 사용자 답변의 서버 저장
- 장기적인 진로 관리 및 행동 과제
- 구직 공고 추천
- 이력서 또는 포트폴리오 작성
- 의료적·심리학적 진단
- 성별에 따른 결과 계산
- MBTI에 따른 결과 계산
- 테스트 결과의 과학적 정확성 주장

## 성공 기준

- 처음 방문한 사용자가 별도 설명 없이 테스트를 시작할 수 있다.
- 테스트를 3분 이내에 완료할 수 있다.
- 사용자가 결과를 보고 자신과 닮았다고 느낀다.
- 사용자가 결과 캐릭터를 매력적이라고 느낀다.
- 모든 결과 유형에 실제로 도달할 수 있다.
- 무작위 응답 시 특정 결과만 과도하게 나타나지 않는다.
- 모바일 브라우저에서 결과 카드를 PNG로 저장할 수 있다.
