# 허들링 클럽 4차 사이클 2차 실험 요약

- 문서 성격: 사용자가 제공한 공지사항을 프로젝트 요구사항으로 정리한 참고 문서
- 정리일: 2026-10-31

## 실험 주제

나만의 커스텀 하네스 제작하기

## 진행 방식

1. PRD와 스토리 Markdown 문서를 준비한다.
2. AI와 Round 8까지 질의응답 인터뷰를 진행한다.
3. 인터뷰를 통해 나만의 하네스를 직접 제작한다.

하네스는 디자인 작업에 한정되지 않는다. AI로부터 반복적으로 일관된 품질의 결과를 받아야 하는 작업이라면 리서치, 데이터 분석 등 다른 종류의 하네스도 가능하다.

## 제출물

1. 산출물 스크린샷 또는 파일
2. GitHub 저장소 링크

## 이 프로젝트의 적용 방식

이 프로젝트에서는 다음을 제출 대상으로 삼는다.

- PRD와 사용자 스토리
- Round 1~8 인터뷰 기록
- 심리테스트 콘텐츠와 점수 모델을 생성·검증하는 Python 하네스
- 하네스가 생성한 `나의 다음 직업 찾기` 정적 웹앱
- 점수 분포 및 결과 도달 가능성 검증 보고서
- 웹앱과 결과 카드 스크린샷
- 전체 소스가 포함된 GitHub 저장소
