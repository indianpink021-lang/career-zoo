# 비주얼 스타일 가이드

> 상태: Round 8 승인 완료

## 출처와 원칙

- 캐릭터의 기준 이미지는 프로젝트 제작자가 직접 그린 원본 3종이다.
- 외부 레퍼런스는 분위기 검토에만 사용하며, 얼굴 배치·신체 비율·포즈·소품을 복제하지 않는다.
- 생성형 이미지 결과는 최종 원화가 아니라 조형 탐색 및 구현 가이드로 사용한다.

## 공통 조형 언어

- 약 1.5~2등신을 기본으로 하되 동물과 포즈에 따라 달라지는 비율
- `#222~#333`의 밝은 차콜색과 미세하게 울퉁불퉁한 픽셀브러시 윤곽선
- 따뜻한 흰색에 가까운 몸색
- 정확한 원이 아닌 불규칙한 픽셀브러시 자국 형태의 눈, 작은 분홍색 코, 최소한의 입
- 매우 짧은 다리와 몸에서 살짝 떨어져 보이는 작은 팔
- 표정보다 자세와 소품에서 드러나는 망충함
- 정교한 털 묘사, 광택, 입체적인 3D 음영은 사용하지 않음

## 색상

- 기본: 웜 화이트, 차콜 블랙
- 유형별 포인트: 코랄, 오렌지, 바이올렛, 그린, 블루, 민트
- 한 캐릭터당 강한 포인트색은 1개를 원칙으로 한다.
- 종이 질감은 사용하지 않는다. 옅은 블러형 볼터치나 그림자는 제한적으로 허용한다.

## 여섯 동물의 구분

- 탐색 토끼: 비대칭으로 꺾인 긴 귀
- 뚝딱 햄스터: 넓은 볼과 작은 둥근 귀
- 기획 고슴도치: 단순한 톱니형 가시 외곽
- 연결 다람쥐: 몸보다 큰 꺾인 꼬리
- 창작 친칠라: 넓은 원형 귀와 위로 선 풍성한 꼬리
- 돌봄 수달: 작은 귀, 낮게 길게 이어지는 꼬리

## 독창성 점검

- 기존 유명 캐릭터와 실루엣, 얼굴 비율, 대표 포즈가 겹치지 않는가?
- 여섯 캐릭터를 검은 실루엣만으로도 구분할 수 있는가?
- 참고 이미지의 의자, 회색 덩어리형 몸, 동일한 표정 기호를 가져오지 않았는가?
- 제작자의 원본에서 추출한 공통 규칙은 유지하되 원본 포즈를 그대로 복사하지 않았는가?
