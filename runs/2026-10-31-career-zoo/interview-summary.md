# Round 1~8 인터뷰 요약

- 실행 ID: `2026-10-31-career-zoo`
- 제품명: `나의 다음 직업 찾기`
- 상태: 완료

## 확정된 제품

현재 직업이 있는 20~40대 직장인·자영업자가 3분 안에 완료하는 모바일 진로 성향 테스트다. 프로필 질문 1개와 상황형 질문 8개를 통해 대표 동물 캐릭터와 보조 업무 성향을 제공한다.

## 확정된 점수 모델

- 다섯 차원: 대상, 진행 방식, 사고와 표현, 변화 선호, 관계 방식
- 각 선택지는 캐릭터 한 표와 `-2~2` 범위의 다섯 차원 벡터를 가진다.
- 캐릭터 표는 질문 내 등장 횟수로 정규화한다.
- 동점은 응답 평균 벡터와 캐릭터 기준 벡터의 거리로 해결한다.
- 현재 직업 분야는 점수에 사용하지 않고 전문성 연결 문구에만 사용한다.

## 확정된 결과

탐색 토끼, 뚝딱 햄스터, 기획 고슴도치, 연결 다람쥐, 창작 친칠라, 돌봄 수달의 여섯 유형을 사용한다. 전체 65,536개 응답 조합에서 각 결과의 비율은 합의한 10~25% 범위에 들어왔다.

## 확정된 비주얼

제작자가 직접 그린 캐릭터 3종의 조형 언어를 기준으로 한다. 불규칙한 눈, 밝은 차콜 픽셀브러시 외곽선, 동물마다 다른 신체 비율, 성격에 맞는 포즈, 제한된 포인트색을 사용한다. 캐릭터 6종은 투명 PNG로 분리했다.

## 생성 범위

Python CLI는 사양 병합, 구조 검증, 결과 분포 시뮬레이션, 정적 웹앱 생성을 수행한다. 웹앱은 백엔드 없이 실행되며 질문 진행, 이전 답변 수정, 결정적 점수 계산, 결과 설명, 결과 카드 PNG 저장, 다시 하기를 제공한다.
